# Skärgård Express

*Parcels by flakmoped through the Swedish skerries.*

An island courier game for Windows: carry parcels on a three-wheeled Swedish flakmoped round a little archipelago of red cottages and granite, with loose cargo that slides and spoils, ferries to catch, weather to ride out and islanders waiting on their post.

**This repository is the game's website and the place to report bugs from the test build.** The game itself isn't here.

- Website: https://cobolt60dev.github.io/skargard-express/
- [Tester guide](https://cobolt60dev.github.io/skargard-express/testers.html): installing, what to try, and where the log is
- [Report a bug or send feedback](../../issues/new/choose)

### Editing the site

It's plain HTML and CSS, served by GitHub Pages from the `main` branch:

- `index.html`: the home page (the game, screenshots, the test build, controls, credits).
- `testers.html`: the tester guide (install, what to try, reporting, known issues, what's in the build).
- `assets/js/site.js`: the download link, its size and the build name, and the feedback link, in one place at the top.
- `assets/img/`: the logo, screenshots (`shots/`, each with a `-thumb`), and the link preview image (`og.jpg`).
- `.github/ISSUE_TEMPLATE/`: the bug report and feedback forms testers fill in.
